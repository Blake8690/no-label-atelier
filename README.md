# NO LABEL ATELIER

Hemsida för NO LABEL ATELIER – ett UF-företag från Stockholm.

Ren HTML/CSS/JS, inga byggsteg. Öppna `html/index.html` i webbläsaren.

## Filer

- `html/index.html` – Hem (startbild, första kollektionen, posters)
- `html/om-oss.html` – Om oss (teamet, kontakt)
- `css/style.css` – utseende
- `js/script.js` – språk (svenska/engelska), varukorg, kassa, formulär m.m. Inställningar högst upp

## Lägga in bilder

Skapa mappen `bilder/` bredvid `html/`, lägg bilden där och byt ut
`<span>Kampanjbild</span>` mot `<img src="../bilder/din-bild.jpg" alt="Beskrivning">`.
